# Bankist App

Bankist is a minimal banking application built with vanilla JavaScript that simulates real-world banking features such as money transfers, loan requests, balance calculation, and transaction history. This project was developed as part of Jonas Schmedtmann’s _Complete JavaScript Course_ to practice modern JavaScript concepts.

## About the Project

Bankist is a simple yet functional banking interface where users can log in using a username and PIN. Once logged in, users can view their account balance, transaction history, and a financial summary. The app also allows users to transfer money to other accounts, request loans based on deposit history, and close their accounts.

The main goal of this project is to strengthen understanding of core JavaScript concepts, DOM manipulation, event handling, and array methods while building a realistic application.

## Features

- User login with username and PIN
- View transaction history (deposits & withdrawals)
- Transfer money between accounts
- Request loans based on account activity
- Close account functionality
- Automatic logout timer for security
- Dynamic balance, summary, and UI updates

## Built With

- HTML5
- CSS3
- JavaScript (ES6+)

## JavaScript Concepts Used

- Array methods (`map`, `filter`, `reduce`, `find`, `some`, `every`, `sort`)
- DOM manipulation
- Event handling
- Timers (`setTimeout`, `setInterval`)
- Date and currency formatting
- State management
